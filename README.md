# Web App Server

Developed with Express 🚀🚀🚀

## Prerequisites

- Node.js v18
- MySQL Workbench
- Docker
- Visual Studio Code / other code editor

## Usage

- Install - `npm run install`
- Run Development - `npm run dev`
- Test lint - `npm run lint`

## Packages
- Nodemon
- Express
- Sequelize
- JsonWebToken
- Bcrypt
- MySQL2
- Dotenv
- Cors
- Eslint
